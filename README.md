# Family Filter Assets

Family-shared AdGuard custom filter distribution.

## AdGuard subscription URL

Use this URL in AdGuard custom filters after GitHub Pages is enabled for this repository:

```text
https://kangsicj.github.io/family-filter-assets/filters/2026/7f3a91c2-family.txt
```

## GitHub Pages setup

Repository settings:

```text
Settings → Pages → Deploy from a branch
Branch: main
Folder: /docs
```

Only the filter file under `docs/filters/2026/7f3a91c2-family.txt` is intended to be shared.
